
🎬 Netflix Data Analysis Project

A complete Netflix Movies & TV Shows Data Analysis project using Python, Pandas, Matplotlib, and Seaborn. This project focuses on data cleaning, exploratory data analysis (EDA), visualization, and insight generation from a movie dataset.

---

📌 Project Overview

The goal of this project is to analyze Netflix/movie-related data and discover useful trends such as:

- Most frequent movie genres
- Most popular genres based on votes
- Highest and lowest popularity movies
- Year with the maximum number of released movies
- Audience preference patterns

This project demonstrates the end-to-end data analytics workflow, from raw data preparation to final business insights.

📊 Key Findings

🎭 Q1: Most Frequent Genre

Drama is the most frequent genre in the dataset.


- Appears in more than 14% of all records
- Dominates among 19+ different genres

---

⭐ Q2: Genre with Highest Votes

Drama also receives the highest popularity and vote share.

- About 25.5% of the dataset contains highly voted movies
- Drama contributes more than 18.5% of popular titles

---

🕷️ Q3: Movie with Highest Popularity

Spider-Man: No Way Home

Genres:

- Action
- Adventure
- Science Fiction

This movie has the highest popularity score in the dataset.

---

🎵 Q4: Movie with Lowest Popularity

The United States, Thread

Genres:

- Music
- Drama
- War
- Sci-Fi
- History

This movie has the lowest popularity score in the dataset.

---

📅 Q5: Year with Most Released Movies

2020 has the highest number of released movies in the dataset.
